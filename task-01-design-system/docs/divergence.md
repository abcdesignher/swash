# Divergence

These are intentional deviations from the typography guidance, not defects.

## 1. Open Sans Display Large line height: 1.3 instead of 1.4-1.6

**Divergence:** Display Large uses a 62px font size with an 80.6px line height, a ratio of 1.3. The recommended range is 1.4-1.6.

**Why:** The recommendation is a guide, not a rule. A 1.3 ratio was chosen deliberately for this display style.

## 2. Playfair added as a second typeface

**Divergence:** The system selectively uses Playfair alongside Open Sans.

**Why:** Playfair provides an expressive option for headings where a more distinctive voice is needed. Open Sans remains the body and interface family for readability.
