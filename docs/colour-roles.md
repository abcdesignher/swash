**Colour Roles**

- **Primary:** Main brand colour for primary actions.
- **Secondary:** Supporting colour for primary activities.
- **Tertiary:** Additional supporting colour for visual variety.
- **On Roles:** Colours used for text and icons on other coloured surfaces.
- **Surface:** Colours used for containers, cards, and panels.
- **Background:** Colour used for the main app background.
- **Outline:** Usually neutral colours used to distinguish surfaces and backgrounds.
- **Elevation:** Colours used to indicate depth and hierarchy between surfaces.
