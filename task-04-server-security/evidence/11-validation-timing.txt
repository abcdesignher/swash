Reading the numbers (medians are more reliable than means here; the first requests in a dev server include compile time, which inflates the 'before' valid mean and max):
- Valid requests: median 39.9 ms -> 57.2 ms (+17.3 ms). The increase is consistent with the ~23 ms Argon2id hash measured in 08-timing-argon-vs-sha.txt plus Zod parsing and a richer insert. It is a deliberate cost.
- Invalid requests: median 31.7 ms -> 16 ms. They were previously accepted (HTTP 201 and a database write). They are now rejected with HTTP 422 before any database or hashing work, so they cost less.
- Limits: dev-server numbers, one machine, sequential requests. I did not measure the Zod parse step in isolation, so I cannot state its cost separately from the hash and the different insert.
