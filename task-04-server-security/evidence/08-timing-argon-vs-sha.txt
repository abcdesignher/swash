--- Guesses per second for ONE thread/core on this machine (arithmetic) ---
Argon2id: 1000 ms / 23.25 ms = 43 guesses/second
SHA-256 : 1000 ms / 1.137e-3 ms = 879,825 guesses/second
Ratio   : 879,825 / 43 = SHA-256 is about 20,459x faster to guess against

--- Worked example: exhausting a 6-character lowercase+digit space (36^6) on this one core ---
36^6 = 2,176,782,336 candidates
SHA-256 : 2,176,782,336 / 879,825 = 2,474.11 seconds
Argon2id: 2,176,782,336 / 43 = 50,618,170.85 seconds (~585.86 days)

Caveats: this is a single-core, CPU-only measurement of Node's implementations. Attackers can use GPUs/ASICs and many cores;
Argon2id's 19 MiB memory requirement per guess is what limits that parallelism. Figures are from this machine only.
