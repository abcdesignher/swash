  verify(hash2, correct password)  -> true
  verify(hash1, wrong password)    -> false

Why they differ: the library generates a fresh cryptographically random salt for every call and
mixes it into the hash. The salt is stored inside the encoded string ($...$salt$hash), so verify()
can recompute the hash. Two users with the same password therefore get different stored hashes,
and precomputed (rainbow) tables are useless.
